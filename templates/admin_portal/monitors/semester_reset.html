Iniciar semestre nuevo

Esta accion archiva el semestre actual y abre un semestre nuevo para registrar monitores, horarios y marcaciones nuevas.

Mensaje importante: los registros del semestre actual se conservan como historico. Los monitores actuales quedaran inactivos para que el nuevo semestre empiece sin conflictos.

Que se va a archivar

Se conservaran monitores, horarios, registros importados, jornadas procesadas, horas extra, anotaciones, inconsistencias, memorandos y reportes para consulta historica.

Las cuentas de monitor se conservan. Si un monitor repite, podra tener un nuevo registro activo sin perder el semestre anterior.
